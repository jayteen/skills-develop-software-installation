# Volta 环境变量官方文档

来源：https://www.voltajs.com/config/env.html

## Core Environment Variables

### `VOLTA_HOME`
- **用途**: 指定 Volta 的根目录，所有数据存放于此
- **默认值**: `$HOME/.volta` (Unix), `%USERPROFILE%\.volta` (Windows)
- **类型**: 系统环境变量
- **说明**: 需在安装前设置，否则 Volta 会使用默认路径

### `VOLTA_LOGLEVEL`
- **用途**: 控制日志输出级别
- **可选值**: `error`, `warn`, `info`, `debug`, `trace`

### `VOLTA_FEATURE_PNPM`
- **用途**: 启用 pnpm 支持
- **说明**: 设置为任意值即可启用

### `VOLTA_NETWORK_TIMEOUT_SECS`
- **用途**: 网络请求超时时间（秒）
- **默认值**: `30`

### `VOLTA_REDIRECT_STDERR`
- **用途**: 将 Volta 自身的输出重定向到 stderr

### `VOLTA_SKIP_SETUP`
- **用途**: 跳过 setup 检查

### `VOLTA_UNSAFE_DIAGNOSTIC`
- **用途**: 启用诊断信息输出

### `VOLTA_TARGET_PROFILE`
- **用途**: 指定 shell profile 文件路径

### `VOLTA_LATEST_VERSION`
- **用途**: 覆盖最新版本检查

### `VOLTA_MIN_COMPATIBLE_VERSION_UPDATE_CHECK`
- **用途**: 最低兼容版本更新检查

### `VOLTA_STDIN_FILE_PASSTHROUGH`
- **用途**: 控制 stdin 文件传递行为

## 注意

- `VOLTA_NODE_MIRROR` **不在此官方文档中**，社区常用但非官方变量
